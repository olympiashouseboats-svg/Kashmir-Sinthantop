Firebase Setup Instructions

Step 1: Go to console.firebase.google.com and create a project named kashmir-sinthan-top

Step 2: Enable Firestore Database (start in test mode)

Step 3: Enable Authentication → Email/Password and create an admin user

Step 4: Copy your Firebase config from Project Settings and replace the firebaseConfig object in all HTML files

Step 5: Collections needed: tours and cars — they are created automatically when you add your first item!
